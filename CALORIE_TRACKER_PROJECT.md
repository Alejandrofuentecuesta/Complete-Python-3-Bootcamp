# Calorie Voice Tracker standalone project

The calorie/exercise tracker MVP has been separated into `calorie-voice-tracker/` so it can be published as an independent GitHub repository.

Start here:

```bash
cd calorie-voice-tracker
npm install
cp .env.example .env.local
npm run dev
```

To publish it as a separate GitHub repo, follow `calorie-voice-tracker/docs/github-publish.md`.
